# map-vectorize

Универсальная **векторизация растровых тематических карт** в GeoJSON: извлечь **ВСЕ
разделы легенды** (площадные единицы; со временем — линии/точки) с **максимальной
точностью**. Векторизация карт­онезависима; геопривязка — **сменный модуль** под тип карты.

Первый вход и пилот — **четвертичка ГГК-1000/3** (ЛО, листы `P-(35),36` и `O-35,36`).
Проект `../mushrooms` (пески `f`/`v`/`lg` для боровых местообитаний) — **один из
потребителей** результата (фильтрует нужные единицы), а не цель проекта.

Главный предел точности — **«цвет ≠ генетический индекс»**: единицы одного цвета, но
разного индекса по цвету не разделить; максимальная точность требует OCR индексов на
теле карты (тяжёлый, частично нерешённый кусок) — см. `pipeline.md`.

## Структура

- `data/raw/` — исходные растры + PDF легенд (**не в git**; тянутся `src/fetch_sources.py`)
- `data/legend/` — извлечённые цвета легенды, таблицы единиц
- `src/` — скрипты конвейера
- `output/` — результат (GeoJSON) — **в git**

## Команды

```
pip install -r requirements.txt
python src/fetch_sources.py           # скачать исходники в data/raw/
python src/georef.py <sheet>          # авто-привязка (номенклатура+сетка → EPSG:4326)
python src/legend.py <raw.jpg>        # авто-палитра легенды (свотчи + OCR индексов)
python src/vectorize.py <sheet> <gen> # классификация по цвету → полигоны единиц → GeoJSON
```

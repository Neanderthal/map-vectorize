# map-vectorize

Векторизация растровых геологических/почвенных карт в GeoJSON.

Первая задача — **карты четвертичных отложений ГГК-1000/3** (1:1 000 000, ВСЕГЕИ,
3-е поколение) на Ленинградскую область. Цель: выделить **песчаные отложения**
(флювиогляциальные `f`, эоловые `v`, озёрно-ледниковые `lg`) как полигоны, чтобы
пересечь их с сосняком и получить кандидатные зоны для белого гриба соснового
(боровика). Потребитель результата — вьюер проекта `../mushrooms`.

## Конвейер

1. **fetch** — скачать листы и легенды с geokniga (`src/fetch_sources.py`).
2. **georef** — привязать лист (коническая проекция карты → EPSG:3857) по узлам
   градусной сетки (GCP) через rasterio.
3. **vectorize** — сегментация заливок по цвету целевых единиц, чистка оверпринта
   (подписи, границы, сетка), полигонизация (`rasterio.features.shapes`) → GeoJSON.

Подробности и осознанные ограничения (приближённость, цвет ≠ генетический индекс) —
в `.claude/rules/`.

## Статус

Старт проекта: исходники ГГК-1000/3 (листы P-(35),36 и O-35,O-36, карты
четвертичных образований) скачаны. Конвейер в разработке.

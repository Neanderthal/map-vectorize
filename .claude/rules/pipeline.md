# Конвейер оцифровки

Растровый лист геокарты → GeoJSON полигонов целевых единиц. Инструменты — `rasterio`,
`numpy`, `scikit-image`, `shapely` (чистый Python, без GIS-CLI; `gdalwarp` в среде нет,
rasterio достаточно).

## 1. Crop — вырезать полотно карты

Лист = карта (слева) + панель легенды (справа) + поля/заголовок. Для сегментации и
привязки нужна только **область внутри рамки (neatline)**. Снять пиксельные координаты
углов рамки визуально (превью) один раз на лист.

## 2. Georef — привязка (коника → EPSG:3857)

Карта в **конической проекции** (не прямоугольная: рамка — трапеция, верх ýже низа).
Поэтому простой bbox-ImageStatic по углам даёт перекос к краям (так сейчас сделан слой
1969 г. в mushrooms — приближённо). Правильно:

- Взять **GCP по узлам градусной сетки** (пересечения линий сетки с известными lon/lat —
  целые градусы). Номенклатурные рамки листов: P-ряд 60–64°N, O-ряд 56–60°N; колонки
  35 = 24–30°E, 36 = 30–36°E.
- `rasterio` + `GroundControlPoint` → `rasterio.warp.reproject` в EPSG:3857.
- Привязанный растр (GeoTIFF) — в `data/work/` (gitignore).

## 3. Vectorize — цвет → полигоны

Тот же приём, что для слоя леса LC100 в mushrooms (`rasterio.features.shapes`):

1. Снять из легенды **точные RGB целевых единиц** (пески `f`, `v`, `lg`) — см. legend.md.
2. Маска по каждому цвету с допуском (в Lab/HSV устойчивее, чем в RGB).
3. **Убрать оверпринт**: подписи-индексы, границы контуров, сетка, реки, значки скважин,
   малиновые пунктиры озов — всё чёрное/яркое поверх заливки рвёт маску. Морфология:
   `closing` закрыть разрывы от подписей, `opening`/remove_small_objects убрать мусор.
4. `rasterio.features.shapes(mask, transform=...)` → полигоны сразу в геокоординатах.
5. `shapely`: упростить (`simplify`), отфильтровать по площади, собрать в GeoJSON
   (EPSG:4326) с атрибутом единицы и рейтингом боровика.

## Осознанные ограничения (без иллюзий)

- Это **приближённая** оцифровка, не геодезическая. Подписи/границы дырявят полигоны;
  близкие оттенки разных возрастов можно спутать.
- **Цвет ≠ генетический индекс.** Надёжно единицу задаёт индекс (fIII, lgIIIos…), но это
  OCR поверх карты — тяжелее; пока опираемся на цвет + ручную валидацию по легенде.
- **Озы/эскеры** (малиновые пунктиры) — линейные песчаные гряды, топ для боровика;
  их полезно вынести отдельным слоем (линии), а не терять как «мусор».
- Результат — **приоритеты для разведки**, не гарантия. Сверять с сосняком и точками
  почв mushrooms.

## Порядок работ

(жёлтый `f`) → оценить качество → потом все единицы и оба листа.

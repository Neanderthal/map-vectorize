# Источники и доступ

## Доступ к .ru (усвоенные грабли)

Эта машина гонит egress через тоннель (Privoxy→Tor, `default dev tor0`). Поэтому:

- **geokniga.org** — тянуть **мимо прокси**: снять `*_proxy`-переменные + `curl --noproxy '*'`.
  К ней маршрут идёт напрямую через wifi (`wlp9s0`), не через Tor. Работает (HTTP 200).
- **ВСЕГЕИ / Карпинский** (`vsegei.ru`, `wega.karpinskyinstitute.ru`, `maps.vsegei.ru`,
  `atlaspacket.vsegei.ru`) — **закрыты UTM-шлюзом**: сервисные хосты отдают **403 Forbidden**
  (`Server: nextgen_0.5`, внутренний TLS-сертификат `CN=auth.vsegei.ru`). Проверено и с
  чистого не-торового IP (принудительно `--interface wlp9s0`) — всё равно 403. Это не
  блокировка Tor, а фильтрация самого хоста. Авторитетного вектора ГГК оттуда не взять.
- Общий внешний трафик выходит через Tor-exit; к .ru-хостам, что резолвятся напрямую,
  идём мимо. `dig @8.8.8.8` не работает — резолв через `getent ahostsv4 <host>`.

## Тупики (проверено — не тратить время заново)

- **ЕГРПР** (`egrpr.esoil.ru`) — геометрия = те же оцифрованные контуры **Фридланда 1:2.5М**
  (1988), 25711 полигонов. Не точнее того, что уже есть в mushrooms.
- **RGIS ЛО / «Экологический атлас»** (`fpd.lenobl.ru`) — полигональные эко-схемы
  (четвертичка, почвы, ландшафты) **сняты с публикации** на их GeoServer (`LayerNotDefined`);
  живы только точки мониторинга почв (вектор, 223 шт. — уже забраны в mushrooms).
- **geokniga /maps/44452** («O-(35),36 Ленинград, 1:200000») — файл 1.2 МБ, обзорный
  скан, **не настоящая 1:200к**. Для реальной 1:200к нужны по-листовые ГГК-200.

## Модель данных

- `data/raw/` — исходные растры + PDF (~130 МБ): **не в git**, воспроизводятся `fetch_sources.py`.
- `output/*.geojson` — результат векторизации: **в git** (маленький, самодостаточный).
- Потребитель — вьюер `../mushrooms` (слой/кандидатные зоны).

## Дальше (не скачано)

- **ГГК-200** (1:200 000) — по-листовая четвертичка на ЛО (~25–30 листов), с geokniga
  через фильтр по номенклатуре (`O-36-I`…). Настоящий прирост разрешения.
